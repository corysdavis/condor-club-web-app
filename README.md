# Project Name: Condor Club

## Project Description
Condor Club is a web app for a made-up golf apparel brand that sells limited releases. Members can create an account, shop and search products, check out with a simulated cart, see upcoming releases, and watch a live raffle draw. Staff can add, edit, and delete products from an admin view.

## Project Tasks
- **Task 1: Plan and set up**
  - Picked the brand concept and mapped out the pages
  - Set up XAMPP, VS Code, and the GitHub repo
- **Task 2: Build the database**
  - Designed 7 connected MySQL tables
  - Added realistic sample data
- **Task 3: Accounts and login**
  - Built registration, login, logout, and change password
  - Added password complexity rules
- **Task 4: Shop and search**
  - Built product search and category filters
  - Added product images pulled from the database
- **Task 5: Cart, checkout, and admin tools**
  - Members can add to cart, update quantities, and place orders
  - Admins can add, edit, and delete products
- **Task 6: Raffle, security, and launch**
  - Built the raffle page with JavaScript
  - Added login lockout and session timeout
  - Hosted the site live on InfinityFree

## Project Skills Learned
- Building a full web app with a back-end database
- Writing secure PHP (hashed passwords, prepared statements, CSRF protection)
- Database design and connecting tables
- Using Git and GitHub to track progress and tag each phase
- Debugging and hosting a live site

## Language Used
- **PHP**: Handles the logic, logins, and database connection.
- **MySQL**: Stores members, products, carts, and orders.
- **HTML/CSS**: Page layout and the brand styling.
- **JavaScript**: Powers the live raffle draw.

## Development Process Used
- **Iterative (Agile-style)**: Built the project in weekly phases, tested each feature as I went, and tagged each phase on GitHub.
